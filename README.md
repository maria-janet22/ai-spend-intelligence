# AI Spend Intelligence

AI-powered platform to analyze company AI tool spending, estimate savings, and generate intelligent audit summaries.

## Features

- AI Spend Audit
- Savings Estimation
- Analytics Dashboard
- Supabase Database Integration
- Responsive UI
- Vercel Deployment

## Tech Stack

- Next.js
- TypeScript
- Tailwind CSS
- Supabase
- OpenAI API
