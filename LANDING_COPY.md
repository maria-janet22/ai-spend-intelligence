# FAQ

## 1. What does the platform do?

The platform analyzes your AI software subscriptions and identifies opportunities to reduce unnecessary spending.

---

## 2. Which AI tools are supported?

The audit currently supports:
- ChatGPT
- Claude
- Cursor
- GitHub Copilot
- Gemini
- OpenAI API
- Anthropic API
- Windsurf

---

## 3. Is my company data secure?

Yes. Sensitive audit reports are not publicly exposed and are stored securely.

---

## 4. Do I need to create an account?

No. Users can generate audits without creating an account.

---

## 5. How are savings calculated?

Savings are estimated using rule-based analysis of subscription overlap, unnecessary premium plans, and optimization opportunities.
